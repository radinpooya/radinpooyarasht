# سامانه اشتراک‌های گاز 🔥 — نسخه GitHub Pages + Supabase

سایت کاملاً استاتیک است و روی **GitHub Pages** (رایگان) میزبانی می‌شود؛ دیتابیس و لاگین با **Supabase** (پلن رایگان) کار می‌کند. دیتای همه ادمین‌ها **مشترک و آنلاین** است.

---

## 🚀 راه‌اندازی — ۶ مرحله (حدود ۱۵ دقیقه)

### مرحله ۱: ساخت پروژه Supabase
1. برو به [supabase.com](https://supabase.com) و ثبت‌نام کن (می‌تونی با اکانت گیت‌هاب وارد بشی — رایگانه).
2. **New Project** → نام دلخواه (مثلاً `gaz-db`) + یک **Database Password** قوی انتخاب کن (جایی ذخیره‌ش کن) → ریجن نزدیک (مثلاً Frankfurt) → **Create**.
3. صبر کن ~۲ دقیقه تا پروژه ساخته بشه.

### مرحله ۲: ساخت جداول (فایل schema.sql)
1. توی داشبورد Supabase از منوی چپ برو به **SQL Editor** → **New query**.
2. کل محتوای فایل **`schema.sql`** این ریپو رو کپی کن و اونجا Paste کن → دکمه **Run**.
3. باید پیام موفقیت (`Success`) ببینی. ✅

### مرحله ۳: خاموش کردن تأیید ایمیل (مهم!)
1. منوی چپ → **Authentication** → **Sign In / Up** (یا Providers).
2. قسمت **Email** → گزینه **Confirm email** رو **خاموش (Off)** کن و Save.
   - چون ایمیل واقعی ارسال نمی‌کنیم، این لازمه تا کاربرها بدون تأیید ایمیل فعال بشن.

### مرحله ۴: ساخت ادمین‌ها
1. **Authentication** → **Users** → **Add user** → **Create new user**.
2. یک ایمیل و رمز بده (ایمیل لازم نیست واقعی باشه؛ مثلاً `admin@gaz.local`) و حتماً تیک **Auto Confirm User** رو بزن.
3. برای هر ادمین دیگه همین کار رو تکرار کن.

### مرحله ۵: گرفتن آدرس و کلید
1. منوی چپ → ⚙️ **Project Settings** → **API**.
2. این دو مقدار رو کپی کن:
   - **Project URL** (مثل `https://abcdefg.supabase.co`)
   - کلید **`anon` `public`** (یک متن طولانی که با `eyJ...` شروع می‌شه)

> 🔒 کلید `anon public` امنیتش با RLS تضمین شده — فقط کاربران لاگین‌شده به دیتا دسترسی دارن. **هرگز** کلید `service_role` رو جایی منتشر نکن!

### مرحله ۶: گذاشتن روی گیت‌هاب
```bash
cd gaz-web
git init
git add .
git commit -m "سامانه اشتراک‌های گاز"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```
بعد توی گیت‌هاب: **Settings → Pages → Branch: `main` / `(root)` → Save**
چند دقیقه بعد سایتت بالا میاد: `https://USERNAME.github.io/REPO-NAME/`

> 💡 ریپو اگه **Public** باشه Pages کاملاً رایگانه. **Private** بودن ریپو + Pages نیاز به GitHub Pro داره (~۴ دلار/ماه). نکته مهم: ریپوی Public هیچ دیتایی لو نمی‌ده چون توی کد اصلاً دیتایی نیست — همه اطلاعات اشتراک‌ها توی دیتابیس Supabase ذخیره می‌شه، نه توی گیت‌هاب.

### اولین ورود
1. سایت رو باز کن → صفحه «اتصال به پایگاه‌داده» میاد → **Project URL** و **anon key** مرحله ۵ رو بزن → اتصال.
2. با ایمیل/رمز ادمین (مرحله ۴) وارد شو.
3. حالا فایل اکسل شرکت گاز رو آپلود کن و شروع کن! 🎉

> می‌تونی به‌جای وارد کردن دستی، URL و کلید رو مستقیم توی فایل `config.js` بذاری تا برای همه از پیش تنظیم بشه.

## 🔄 آپدیت از نسخه قبلی؟

اگر قبلاً `schema.sql` نسخه قدیمی را اجرا کرده‌ای، کافی است **کل فایل `schema.sql` جدید را دوباره** در SQL Editor اجرا کنی — دیتا پاک **نمی‌شود**. دو چیز جدید اضافه می‌شود:
- منطق جدید بررسی: شماره **ناموجود در لیست شرکت گاز** یا **تکراری** دیگر ثبت نمی‌شود؛ فقط **خطا** گزارش می‌شود (به‌همراه نام مدیر پروژه و ممیزِ ثبت اول).
- کارت جدید «فایل ثبت‌شده‌های قبلی»: برای وارد کردن لیست اشتراک‌هایی که قبل از این سیستم ثبت کرده‌ای (فقط بار اول).

## ⚙️ نکات فنی

| موضوع | توضیح |
|---|---|
| محدودیت رایگان Supabase | ۵۰۰ مگابایت دیتابیس + ۵ گیگابایت ترافیک/ماه — برای صدها هزار رکورد کافیه |
| خواب رفتن پروژه | پلن رایگان بعد از ~۷ روز **عدم استفاده** موقتاً Pause می‌شه؛ با یک بازدید از داشبورد Supabase بیدار می‌شه |
| پشتیبان‌گیری | دکمه «💾 پشتیبان‌گیری کامل» در تب آپلود فایل — جزئیات پایین ⬇ |
| امنیت | دیتا فقط با لاگین (ایمیل+رمز) دیده می‌شه (Row Level Security فعاله) |
| فایل‌های نمونه | پوشه `samples/` قالب فایل‌های اکسل مورد انتظار رو نشون می‌ده |

## 💾 پشتیبان‌گیری و قطعی اینترنت

### پشتیبان‌گیری کامل (ماهی یک‌بار انجام بده!)

در سایت ← تب **آپلود فایل** ← کارت **«💾 پشتیبان‌گیری و کار بدون اینترنت»** ← دکمه **«دانلود پشتیبان کامل»**:

1. فایل `پشتیبان-ثبت‌شده‌ها-....xlsx` — همه اشتراک‌های ثبت‌شده با مدیر، ممیز و تاریخ.
2. فایل `پشتیبان-لیست-شرکت-گاز-....csv` — کل لیست شرکت گاز (حتی ۷۴۰ هزار شماره).

هر دو را روی **کامپیوتر یا فلش** نگه دار. با این دو فایل، حتی اگر کل سیستم از بین برود، همه‌چیز قابل بازسازی است:
- بازگردانی لیست گاز: تب آپلود فایل ← کارت ۱ ← حالت «جایگزینی کامل» ← فایل CSV.
- بازگردانی ثبت‌شده‌ها: تب آپلود فایل ← کارت ۲ ← فایل اکسل ثبت‌شده‌ها (ستون‌های مدیر/ممیز خودکار خوانده می‌شوند؛ تاریخِ بازگردانی، تاریخ روز آپلود ثبت می‌شود).

### 📴 نسخه آفلاین — وقتی اینترنت قطع است

فایل **`offline.html`** نسخه کاملاً مستقل سایت است: **بدون اینترنت، بدون گیت‌هاب، بدون Supabase** روی هر کامپیوتری کار می‌کند.

**آماده‌سازی (یک‌بار، وقتی اینترنت هست):**
1. در گیت‌هاب ← صفحه ریپو ← دکمه سبز **Code** ← **Download ZIP** ← فایل را استخراج کن (پوشه‌ای با همه فایل‌های سایت، از جمله `offline.html`).
2. این پوشه را روی کامپیوتر/لپ‌تاپ کاری نگه دار (فلش هم می‌شود). همین!

**کار در روز قطعی اینترنت:**
1. فایل `offline.html` را دابل‌کلیک کن (مرورگر باز می‌شود — کروم یا اج پیشنهاد می‌شود).
2. یک‌بار (اولین بار) فایل ۱ (لیست شرکت گاز) و فایل ۲ (ثبت‌شده‌ها) — یا فایل‌های پشتیبان بالا — را در کارت‌های ۱ و ۲ وارد کن. داده‌ها **در همان مرورگر ذخیره می‌شوند** و دفعه بعد نیازی به تکرار نیست.
3. فایل روزانه را در کارت ۳ بررسی کن — همان منطق سایت اصلی: ناموجود ❌ / تکراری 🔁 (با مشخصات ثبت اول) / ثبت جدید ✅.
4. ثبت‌های جدید به‌صورت آفلاین نگه داشته می‌شوند و فردا چکِ تکراری هم درست کار می‌کند.

**بعد از برگشت اینترنت (انتقال به دیتابیس اصلی):**
1. در صفحه آفلاین، کارت ۴ ← دکمه **«⬇ خروجی ثبت‌های جدید»** را بزن.
2. سایت اصلی را باز کن ← تب آپلود فایل ← **کارت ۲ (ثبت‌شده‌های قبلی)** ← فایل خروجی را آپلود کن (مدیر و ممیز خودکار خوانده می‌شوند، تکراری‌ها خودکار رد می‌شوند).
3. برگرد به صفحه آفلاین ← دکمه **«پاک‌کردن لیست انتقال»** را بزن. تمام! ✅

> ⚠️ نکته: داده‌های آفلاین مخصوص همان مرورگر/کامپیوتری است که در آن کار می‌کنی — پس همیشه با یک مرورگر مشخص کار کن.

### چرا این طرح امن است؟ (خلاصه وضعیت‌ها)

| وضعیت | سایت اصلی | دیتابیس | نسخه آفلاین | داده‌ها |
|---|---|---|---|---|
| اینترنت عادی | ✅ | ✅ | ✅ (لازم نیست) | ✅ |
| فیلتر/قطع دسترسی به گیت‌هاب | ❌ | بستگی به فیلتر دارد | ✅ روی لپ‌تاپ | ✅ |
| قطع کامل اینترنت بین‌الملل | ❌ | ❌ | ✅ روی لپ‌تاپ | ✅ + بعداً سینک |
| محدودیت/توقف سرویس‌ها در آینده | ❌ | ❌ | ✅ روی لپ‌تاپ | ✅ با فایل‌های پشتیبان |

- **فایل‌های سایت مال خودت است**: همان ZIP دانلودشده + فایل‌های آپدیت، کل سایت هستند؛ هر جا بخواهی می‌توانی دوباره آپلودشان کنی.
- **هیچ‌وقت فقط روی یک جا تکیه نکن**: پشتیبان ماهانه + پوشه آفلاین روی فلش = حتی در بدترین حالت هیچ‌چیز از دست نمی‌رود.

### توقف پروژه Supabase (خوابیدن بعد از ۷ روز بی‌فعالیتی)

- پلن رایگان اگر **۷ روز هیچ درخواستی** به دیتابیس نرسد، پروژه را Pause می‌کند (خطر واقعی: قطعی طولانی اینترنت!).
- تا **۹۰ روز** با یک کلیک برمی‌گردد: [supabase.com](https://supabase.com) ← ورود ← پروژه ← دکمه **Restore project** (چند دقیقه طول می‌کشد). دیتا سر جایش است.
- پس اگر اینترنت بیش از چند هفته قطع بود، اولین کار بعد از وصل‌شدن: باز کردن داشبورد Supabase و Restore.
- مصرف فضای ما: لیست ۷۴۰ هزارتایی ≈ حدود ۶۰–۸۰ مگابایت + ثبت‌های ۵ سال (~۴۰–۵۰ هزار ردیف) ≈ حدود ۱۰ مگابایت → جمعاً حدود **۱۵–۲۰٪ سهمیه رایگان ۵۰۰ مگابایتی**. جای نگرانی نیست. ✅
