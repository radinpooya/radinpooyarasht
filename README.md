# سامانه اشتراک‌های گاز 🔥 — نسخه GitHub Pages + Supabase

سایت کاملاً استاتیک است و روی **GitHub Pages** (رایگان) میزبانی می‌شود؛ دیتابیس و لاگین با **Supabase** (پلن رایگان) کار می‌کند. دیتای همه ادمین‌ها **مشترک و آنلاین** است.

---

## 🚀 راه‌اندازی — ۶ مرحله (حدود ۱۵ دقیقه)

### مرحله ۱: ساخت پروژه Supabase
1. برو به [supabase.com](https://supabase.com) و ثبت‌نام کن (می‌تونی با اکانت گیت‌هاب وارد بشی — رایگانه).
2. **New Project** → نام دلخواه (مثلاً `gaz-db`) + یک **Database Password** قوی انتخاب کن (جایی ذخیره‌ش کن) → ریجن نزدیک (مثلاً Frankfurt) → **Create**.
3. صبر کن ~۲ دقیقه تا پروژه ساخته بشه.

### مرحله ۲: ساخت جداول (فایل schema.sql)
1. توی داشبورد Supabase از منوی چپ برو به **SQL Editor** → **New query**.
2. کل محتوای فایل **`schema.sql`** این ریپو رو کپی کن و اونجا Paste کن → دکمه **Run**.
3. باید پیام موفقیت (`Success`) ببینی. ✅

### مرحله ۳: خاموش کردن تأیید ایمیل (مهم!)
1. منوی چپ → **Authentication** → **Sign In / Up** (یا Providers).
2. قسمت **Email** → گزینه **Confirm email** رو **خاموش (Off)** کن و Save.
   - چون ایمیل واقعی ارسال نمی‌کنیم، این لازمه تا کاربرها بدون تأیید ایمیل فعال بشن.

### مرحله ۴: ساخت ادمین‌ها
1. **Authentication** → **Users** → **Add user** → **Create new user**.
2. یک ایمیل و رمز بده (ایمیل لازم نیست واقعی باشه؛ مثلاً `admin@gaz.local`) و حتماً تیک **Auto Confirm User** رو بزن.
3. برای هر ادمین دیگه همین کار رو تکرار کن.

### مرحله ۵: گرفتن آدرس و کلید
1. منوی چپ → ⚙️ **Project Settings** → **API**.
2. این دو مقدار رو کپی کن:
   - **Project URL** (مثل `https://abcdefg.supabase.co`)
   - کلید **`anon` `public`** (یک متن طولانی که با `eyJ...` شروع می‌شه)

> 🔒 کلید `anon public` امنیتش با RLS تضمین شده — فقط کاربران لاگین‌شده به دیتا دسترسی دارن. **هرگز** کلید `service_role` رو جایی منتشر نکن!

### مرحله ۶: گذاشتن روی گیت‌هاب
```bash
cd gaz-web
git init
git add .
git commit -m "سامانه اشتراک‌های گاز"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```
بعد توی گیت‌هاب: **Settings → Pages → Branch: `main` / `(root)` → Save**
چند دقیقه بعد سایتت بالا میاد: `https://USERNAME.github.io/REPO-NAME/`

> 💡 ریپو اگه **Public** باشه Pages کاملاً رایگانه. **Private** بودن ریپو + Pages نیاز به GitHub Pro داره (~۴ دلار/ماه). نکته مهم: ریپوی Public هیچ دیتایی لو نمی‌ده چون توی کد اصلاً دیتایی نیست — همه اطلاعات اشتراک‌ها توی دیتابیس Supabase ذخیره می‌شه، نه توی گیت‌هاب.

### اولین ورود
1. سایت رو باز کن → صفحه «اتصال به پایگاه‌داده» میاد → **Project URL** و **anon key** مرحله ۵ رو بزن → اتصال.
2. با ایمیل/رمز ادمین (مرحله ۴) وارد شو.
3. حالا فایل اکسل شرکت گاز رو آپلود کن و شروع کن! 🎉

> می‌تونی به‌جای وارد کردن دستی، URL و کلید رو مستقیم توی فایل `config.js` بذاری تا برای همه از پیش تنظیم بشه.

## ⚙️ نکات فنی

| موضوع | توضیح |
|---|---|
| محدودیت رایگان Supabase | ۵۰۰ مگابایت دیتابیس + ۵ گیگابایت ترافیک/ماه — برای صدها هزار رکورد کافیه |
| خواب رفتن پروژه | پلن رایگان بعد از ~۷ روز **عدم استفاده** موقتاً Pause می‌شه؛ با یک بازدید از داشبورد Supabase بیدار می‌شه |
| پشتیبان‌گیری | هر وقت خواستی از «سوابق ثبت → خروجی اکسل» بکاپ بگیر، یا از داشبورد Supabase → Database → Backups |
| امنیت | دیتا فقط با لاگین (ایمیل+رمز) دیده می‌شه (Row Level Security فعاله) |
| فایل‌های نمونه | پوشه `samples/` قالب فایل‌های اکسل مورد انتظار رو نشون می‌ده |
